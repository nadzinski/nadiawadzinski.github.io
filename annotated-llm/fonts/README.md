# Diagram and reading fonts

Copied from the primer's `site/public/fonts/` on 2026-09-12. These are the same
self-hosted fonts used by the book; their SIL Open Font Licenses are included.

- STIX Two Text: prose and precise mathematical notation.
- Source Serif 4: marginal notes and captions outside the drawing.
- Kalam: diagram lettering and handwritten annotations.
- Source Sans 3: precise sans-serif diagram labels.

Navigation and controls use the book's Arial / Helvetica stack. Font files are
served locally, with no external font requests.
